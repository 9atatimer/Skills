# Skills

An agent-agnostic skill repository for coding agents.

## What is this?

This repository hosts reusable **skills** — discrete, self-contained capability modules that can be loaded by any compatible coding agent regardless of the underlying platform or provider (GitHub Copilot, Claude, GPT, etc.).

## Structure

Skills will be added as they are developed. Each skill will live in its own directory and include:

- A skill definition file describing the skill's purpose and interface
- Any supporting assets or configuration needed by the skill

## Usage

Skills in this repository are designed to be agent-agnostic. They can be referenced and consumed by any agent that supports the skill protocol used here.
