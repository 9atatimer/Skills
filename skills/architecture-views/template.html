Seam Abstractions

A seam is a place where behavior can change without editing the code that uses it (Feathers, Working Effectively with Legacy Code). Each comes in one of three kinds: a port, an interface that adapters plug into; a policy, a rule value handed to a use case; or a parameter, a tuned value supplied from outside. The composition root chooses which adapter, policy or value is used. To swap something listed here, write one new adapter, policy or value and change the root. Anything not listed is hard-wired.
